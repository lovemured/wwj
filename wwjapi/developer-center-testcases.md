> 来源：禅道 STORY #19849《开发者中心》及附件页面原型。需求未明确的规则已列入待确认事项。

## 测试范围

| 范围 | 说明 |
|---|---|
| 页面与权限 | 开发者中心入口、角色权限、套餐可见性、PC 页面展示 |
| API 接入 | 文档说明、AccessKey/SecretKey 展示、复制、重置、申请 |
| 事件订阅 | 模块切换、事件勾选、全选、搜索、套餐锁定、配额 |
| Webhook | HTTPS 地址、回调 Token、测试推送、签名、重试、幂等 |
| BMS 开通 | 接口开通/关闭申请、审核、通知同步、权限生效 |
| API 安全与质量 | HMAC 认证、越权、防重放、限流、数据隔离、兼容性 |
